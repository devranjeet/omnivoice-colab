
# OmniVoice Studio — Hindi & English AI Voice

Run **OmniVoice Studio** easily on Google Colab with Cloudflare Tunnel, no complex setup required.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/h-ravi/ominivoice_ui/blob/main/OmniVoice_Colab.ipynb)

---

## 🧠 About

This is a modern **FastAPI Studio & Google Colab edition** of the original OmniVoice model.
It features a custom **Studio Web UI** with **Cloudflare Tunnel** support, designed for ultra-fast, zero-setup Hindi & English Storytelling, Voice Cloning, and Character Voice Design.

---

## 🔹 Key Features

* 🎙️ **Voice Design & Storytelling**: Deep Narrator, Dadi Ma, Mythological, Kids Story, and Horror Whispers presets.
* 👥 **Zero-Shot Voice Cloning**: Drag-and-drop reference audio or record directly via in-browser Microphone.
* 🎭 **Emotion & Dramatic Tags**: Insert `[laughter]`, `[sigh]`, `[surprise-oh]`, `[question-ah]` seamlessly.
* 🌐 **Cloudflare Tunnel (`cloudflared`)**: Free, public HTTPS access with 1 click on Google Colab.
* ⚡ **High Quality & Fast**: 24kHz studio-quality output powered by OmniVoice neural engine.
